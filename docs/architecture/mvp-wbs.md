# MVP 実装 WBS

この文書は、Tulpa の MVP 実装を簡易に進捗管理するための WBS です。個人開発を前提に、厳密な工数管理ではなく、`未着手 / 進行中 / 完了 / 保留` を追える最小構成にしています。

ロードマップは [mvp-implementation-roadmap.md](./mvp-implementation-roadmap.md) を参照し、この文書では「何をいつ完了とみなすか」を管理します。各タスクは必要に応じて ExecPlan に分解します。

---

## 1. 使い方

1. 着手するタスクの状態を `進行中` にする
2. 大きいタスクは ExecPlan を作成し、ExecPlan 名を記録する
3. チェック項目が埋まり、受け入れ確認が終わったら `完了` にする
4. 判断待ちがある場合は `保留` にし、理由を短く書く

状態の定義:

- `未着手`: まだ着手していない
- `進行中`: 実装または設計を進めている
- `完了`: チェック項目が埋まり、受け入れ確認まで終わった
- `保留`: 未決事項や外部要因で止めている

## 5. 更新ルール

- タスクを `進行中` にしたら、対応する ExecPlan を作るか追記する
- タスクを `完了` にしたら、ExecPlan の `Validation and Acceptance` を確認する
- `保留` にした場合は、[open-questions.md](./open-questions.md) へ必要な追記を行う
- 新しいタスクを増やすときは、先に [mvp-implementation-roadmap.md](./mvp-implementation-roadmap.md) との整合を確認する
