# 実装前の未決事項一覧

このドキュメントは、MVP 文書レビューを一巡した時点で残っている判断待ち項目をまとめた一覧です。AI エージェントが実装へ進む前の確認にも使いますが、固定された TODO リストではなく、実装を進めながら更新する運用ログとして扱います。

---

## 1. 使い方

- `未解決`: まだ判断待ちの項目
- `運用確定`: 当面は運用で吸収すると決めた項目
- `将来送り`: 今は対象外で、Phase 2 以降で別途設計する項目
- `解消済み`: 設計書へ反映し、この一覧では履歴としてだけ残す項目

原則として、対象実装に直結する `未解決` が残ったままコード実装へ進みません。`運用確定` と `将来送り` は、現在の MVP 実装を止めない前提で管理します。`解消済み` は、設計書へ反映した後に履歴として残すか、不要なら削除します。

実装中の更新ルール:

1. 実装前に、対象タスクへ直接効く項目だけ確認する
2. 実装中に新しい判断待ちが出たら、この文書へ追加する
3. 判断が固まったら、元の設計書へ反映する
4. 反映後に、この文書の状態を `解消済み` に変えるか、一覧から削除する

## 5. 更新テンプレート

新しい項目を追加するときは、次の形を使います。

```text
### 章番号 項目名

状態: `未解決`

- 判断待ちの内容
- 影響する設計や実装

関連文書:

- path/to/doc.md
```

設計書へ反映した後は、必要に応じて次のように残します。

```text
状態: `解消済み`
反映先:
- path/to/doc.md
```

## 6. AI 実装前チェック

実装に入る前に次を確認します。

1. `未解決` に残っている項目が、対象実装に直接影響しないか
2. `運用確定` とした項目を、AI が勝手に機能化しようとしていないか
3. `将来送り` の項目を MVP の migration や画面に持ち込もうとしていないか

判断に迷ったら、まず設計書を更新し、必要なら `notes/` に個別メモを追加します。
