# Meta Behavior Knowledge

## Purpose

エージェント運用で「規約として固定すべきこと」と「スキルとして実行すべきこと」を混同しないための短い知識ノートである。

## Rule of Separation

- 規約: エージェントが従うべき行動契約
- スキル: その契約を実行するための手順

## Put It in a Rule When

- リポジトリ全体の履歴や判断基準に効く
- スキルを使わない人間や別エージェントにも共有されるべき
- 「正式ルールはどこか」が曖昧だと困る

例:

- コミットメッセージ規約
- ExecPlan を作る条件
- `AGENTS.md` に何を書いてよいか

## Put It in a Skill When

- 差分や文脈を見て具体的な出力を組み立てる
- 規約を実際の作業へ落とす順番やチェック項目が必要
- 同じ作業を何度も再現したい

例:

- 差分からコミットメッセージ案を作る
- learnings を JSON に切り出す
- requirements レビューを進める

## Compression Rule

この話題は肥大化しやすいので、ここでは判断軸だけを書く。
具体例やテンプレートは、それぞれの運用文書やスキル参照資料に逃がす。
