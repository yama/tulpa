# Agent Knowledge

このディレクトリは、生の学び (`.agents/learnings/`) を人間向けに整理した知識を置く場所です。

- トピック別の要約
- 昇格済みルールの背景説明
- 複数スキルで共有したい補足ガイド
- 索引と棚卸しメモ

基本の入口は `MEMORY.md` です。通常は手動更新ではなく `php scripts/agents/refresh_memory.php` で索引を再生成してください。
将来検討項目は `future-considerations.md` に集約し、散在させないでください。

`AGENTS.md` を長文化させたくなったときは、まずここへ逃がせるか確認してください。
